# Approved starting point

The imported application is the user-approved **0.1.1a1** package with its
embedded editor and contact-zero workflow. Application modules and tests were
copied unchanged from the approved archive.

Source archive: Xlook_Python_Contact_Zero_Update.zip

SHA256: `2a63acc74a6e98dc9a3c5cec0f59192c0f5f93be42051dd15ee1be6dded95afc`

The archive was restored after the external-editor experiment was rejected.
That experiment is not included in this repository. The repository layout adds
version-control documentation, templates and CI around the approved code.

The synthetic CSV and demonstration calibrations are safe teaching/test
fixtures, not calibration values for laboratory experiments. The original
full-experiment validation summary is historical evidence, not a bundled raw
dataset or a claim that the operator's physical contact picks are validated.

The first release/tag is v0.1.1a1. It is created by GitHub Actions after both
baseline test jobs pass on main. Future accepted changes receive new versions.
