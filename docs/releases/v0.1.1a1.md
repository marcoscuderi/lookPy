# lookPy approved baseline — 0.1.1a1

First GitHub checkpoint of the approved embedded-editor application.

- Monokai/Light Python editor, line numbers and font-size controls.
- Picked-contact zeroing with independent ram contact records.
- Standard reduction API, central calibration registry and manifest snapshots.
- Interactive dual-axis plots, picking and configurable velocity estimation.

The package/import/launch name remains `xlookpy`. Use the Conda/Git instructions
in README.md; existing reduction scripts are compatible.

The numerical baseline has 20 tests. Linux and macOS offscreen Qt jobs must pass
before this baseline release is published. This does not certify native Mac
desktop behaviour or scientifically approve operator-selected references.

Rate-and-state modelling/inversion, section execution, stick-slip catalogues,
mechanical-stage composition and additional Xlook command compatibility remain
outside this baseline. No open-source redistribution license has been selected.
